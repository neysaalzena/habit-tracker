# Habit Tracker

Aplikasi web untuk mencatat dan memantau kebiasaan sehari-hari.

## Fitur
- Registrasi, login, dan logout
- Dashboard dan statistik
- Tambah, lihat, edit, dan hapus habit
- Tracking berdasarkan tanggal
- Riwayat aktivitas
- Pengelolaan kategori
- Profil pengguna
- Manajemen pengguna oleh admin
- Progressive Web App (PWA)

## Teknologi
- HTML, CSS, JavaScript
- Node.js dan Express
- MariaDB
- JWT dan bcrypt

## Persyaratan
- Node.js dan npm
- XAMPP dengan MySQL/MariaDB

## Instalasi
1. Clone repository.
2. Jalankan `npm install`.
3. Aktifkan MySQL di XAMPP.
4. Impor `database/schema.sql` melalui phpMyAdmin.
5. Buat file `.env` berdasarkan `.env.example`.
6. Jalankan `npm start`.
7. Buka http://localhost:3000.

## Keamanan
Jangan unggah file `.env` ke repository publik.
